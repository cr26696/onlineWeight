# Online Weight Measurement System

本项目是一个基于ESP8266的在线重量测量系统，主要用于工厂或仓库环境中对物品进行称重并通过WiFi将数据上传到服务器。

## 技术架构

### 硬件平台
- 主控芯片: ESP8266 (ESP-12E)
- 重量传感器: HX711 24位ADC
- 显示模块: MAX7219驱动的8位数码管
- 按键输入: 多个功能按键

### 软件框架
- 开发环境: PlatformIO
- 核心框架: Arduino for ESP8266
- 依赖库:
  - WiFiManager: 用于WiFi配置和连接管理
  - HX711: 重量传感器读取
  - EEPROM: 持久化存储配置参数
  - Ticker: 定时任务处理
  - MAX7219: 数码管显示驱动

## 核心功能

### 1. 重量测量
- 使用HX711 ADC芯片读取重量传感器数据
- 支持皮重扣除（去皮功能）
- 支持校准功能，可调整测量精度
- 重量数据实时显示在数码管上

### 2. 数据显示
- 使用MAX7219驱动芯片控制8位数码管
- 分上下两排显示，每排4位数字
- 支持数字和部分字母显示（如E、H、L、P等）
- 锁定重量时具有闪烁提示功能

### 3. 网络通信
- 使用WiFiManager自动连接WiFi网络
- 支持HTTPS安全通信协议
- 可通过POST或GET方式上传数据到服务器
- 数据上传后根据服务器响应决定是否解锁重量

### 4. 数据持久化
- 使用EEPROM存储校准参数和皮重
- 防止断电后丢失关键配置信息

### 5. 用户交互
- 支持扫码枪输入产品批次和员工信息
- 多按键设计支持去皮、校准、确认上传等功能
- 数码管实时显示相关信息

## 系统工作流程

1. 系统启动后通过WiFiManager连接WiFi网络
2. 初始化重量传感器和显示模块
3. 实时读取并显示重量信息
4. 通过扫码枪扫描产品批次码和员工码
5. 确认后将重量数据上传至服务器
6. 根据服务器响应决定是否解锁继续称重

## 引脚定义

```
D0 - HX711_DT (重量传感器数据)
D1 - HX711_SCK (重量传感器时钟)
D2 - CHECK_MINUS_BUTTON (校准减量按键)
D3 - CHECK_PLUS_BUTTON (校准增量按键)
D4 - ZERO_BUTTON (去皮按键)
D5 - CONFIRM_BUTTON (确认上传按键)
D6 - MAX7219_DIN (显示数据输入)
D7 - MAX7219_CS (显示片选)
D8 - MAX7219_CLK (显示时钟)
```

## 数据上传格式

系统支持两种数据上传方式：

### POST方式（推荐）
```json
{
  "base": "产品基础名称",
  "batchNo": "批次编号",
  "id": "箱子ID",
  "name": "发货人名称",
  "phone": "发货人电话",
  "weight": 重量数值
}
```

### GET方式
通过URL参数传递数据，格式为：
```
/base/batchNo/id/name/phone/weight
```
